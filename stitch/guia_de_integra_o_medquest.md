# Guia de Integração MedQuest

Este documento resume as telas e o sistema de design criados para o projeto MedQuest, utilizando a identidade visual **Clinical Precision**.

## 1. Sistema de Design (Clinical Precision)
O sistema de design define a linguagem visual da plataforma:
- **Cores:** Azul Médico Profissional (`#1a4b84`), Cinzas Técnicos e Verdes de Progresso.
- **Tipografia:** Fonte **Inter** para legibilidade máxima.
- **Componentes:** Botões nítidos, sombras sutis e uso generoso de espaços em branco.
